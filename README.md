# JavaScript Practical Exercises

A collection of short JavaScript exercises.

## What it covers

- Selecting elements (`getElementById`, `querySelector`, by name and tag)
- Creating, cloning and inserting elements; changing attributes, classes and styles
- Events, event delegation and `preventDefault`
- Promises
- Small algorithms: BMI, bus stops, finding all occurrences and more

## How to run

Open an `.html` file in a browser, or run a `.js` file with `node <file>.js`.
